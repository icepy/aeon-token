# 受控方向标签表

比对层（跨周）的**行**只从这里取。模型只能挑，不能自造。

## 为什么必须受控

比对是跨周的。第一周写「世界模型」、第三周写「WAM 方向」，两行永远对不上 ——
「首次点亮日期」和「滞后天数」就算不出来。"首次"这个词本身要求标签第一次出现时就定死。

## 规则

1. **只从本表挑。** 装不下就写 `?`，**不自造新标签**（自造会让历史对不上）。
2. **首次即冻结。** 一条命中的方向打上就不再改，即使后来觉得不对。
3. **挑不出来写 `?`，别留空。** 空值和 `?` 是两件事：空 = 没看，`?` = 看了但装不下。
4. **`?` 是信号，不是终点。** 同一形态连续两轮都落 `?` → 该加标签了（`第一视角感知`
   就是这么加的）。一个标签连续多轮无命中 → 该补词或该删标签。
5. **可以多选。** 一条命中确实横跨两个方向时写 `A/B`。**顺序不敏感但首次即冻结。**
   多选的意义：新加标签不会把老标签的命中抢走，历史序列不断裂。
6. **`不算` 列和 `算` 列同等重要。** 边界靠不算列划，不靠算列。

标签存在 `memory/arxiv-labels.tsv`（`键 \t 方向`，无表头，append-only，脚本不写）。
命中流水在 `memory/arxiv-{arxiv,github}-hits.tsv`（3 列，无方向列）。两张表比对时 join。

## 一、AI / 机器人

| 标签 | 算什么 | 不算什么 |
|---|---|---|
| `具身数据` | 数据引擎、采集管线、数据集构建、第一视角人类数据 | 纯算法（无数据侧贡献） |
| `第一视角感知` | 以第一视角/机上传感器为输入：感知、建图、行人/物体动力学、避障、导航 | 只做数据采集（→`具身数据`）；纯规划无感知 |
| `世界模型` | 环境动力学建模、latent dynamics、world-action model、可预测的仿真器 | 只是用仿真器做数据（→`具身数据`） |
| `抓取与操作` | grasping、manipulation 的广义 | 特指多指/灵巧（→`灵巧操作`） |
| `灵巧操作` | 多指手、dexterous、in-hand 操作 | 简单夹爪抓取（→`抓取与操作`） |
| `遥操作` | teleop、动捕驱动、人机映射 | 纯仿真训练 |
| `sim-to-real` | 迁移方法本身（域随机化、系统辨识、real2sim2real） | 只在仿真里评测 |
| `VLA` | 视觉-语言-动作模型、端到端策略 | 纯 VLM 无动作头 |
| `agent` | 工具调用、多步规划、自我改进的通用 agent | 单步策略（→`VLA`） |
