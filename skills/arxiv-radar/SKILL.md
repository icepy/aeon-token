> **${var}** — 可选，空格分隔，可组合。`dry-run` 跳过 notify、不写 seen 与 hits；`days:N` 换窗口（**默认 30**）；`names` 切到"机制/名字反查"模式；`check:<词>` 量一个候选词的两个口径后退出；`notify:script` 让脚本自己发通知（默认不发，见下）。**原样传给脚本，不要自己解析。**

发现层的第一条通道。

## 为什么是 30 天，不是 7 天

**窗口是流量旋钮，但这条通道的旋钮被索引滞后卡死了。**

- 索引滞后实测 **5 天**（`窗口内最新收录` 连续 5 天没动）→ 7 天窗有效覆盖只剩 **2 天**
- 30d 首跑实测：26 条幸存，与 `seen` 重叠 **0**，`published` 全在 09-28→10-17
- 成本几乎为零：24 词 / 62 原始 / 97s

首跑会一次性推出沉积层（`NOTIFY_TOP=30` 不会截断），之后即稳态。

**但旋钮只在词表对得上时有效。** 实测：那 26 条在**旧 20 词表**下 7d / 30d / 90d **三档都看不见** —— 同一片存量上，10-25 的 90d 正式跑原始 90、幸存 0；两次跑唯一差异就是新加的 4 个 `cat:cs.RO` 词。**词表对不上时，拉多长窗口都是零。**

所以窗口的真实作用只有两件：① 抗索引滞后（5 天）；② **词表改动后的补历史** —— 加词 / 改 carrier 后跑一次 `days:60`。

**顺序不能反：词表决定你能看见什么，窗口决定你能不能补上错过的。**

## 各通道有自己的有效域

**本通道结构上就是 AI / 机器人传感器。** 实测：同一有效窗口内加密词 0 条、机器人词 26 条。

- 加密词留着当**低频探针**，别因 0 命中删
- **跨通道比较只在有效域内做**
- 单侧读数每轮必须记

## 为什么用 arXiv

它是唯一"项目起源 + 有中心索引"的交叉点：论文先于主网、先于上市、先于叙事。PEARL 那篇 2026-06-03 的论文如果被扫到，提前量是 4 个月。

**但记住：arXiv 索引的是「机制」，不是「项目」。** 项目名（XMAQUINA）多半全期零命中；普通英文词（NOTE）会被英文用法污染。所以词表要写**持仓依赖的机制**，不是持仓的名字。

## 词表在哪

**全在 `skills/arxiv-radar/scan.py`。** `TERMS` / `CARRIER_BY_TERM` / `EXCL` 都在那个文件里，改词改那里，**不要在 SKILL.md 里再抄一份**。

## 铁律

- **预算是铁律：全程 ≤ 8 次工具调用。** 成本 = 调用数 × 每次重读上下文（~53k）。**别用 `python3 -c` 探产物结构** —— 先看有没有子命令。
- **写 / 覆写文件一律用 Write 工具，不要用 `echo >`。** 实测 `Bash(echo>)` 会被权限层拒 —— 那一轮就是因为这个，中文稿没写成、机械英文版原样发了出去。追加用 `>>`（`cat >> f <<'EOF'` 形态）。
- **通知正文归模型，不归脚本。** 脚本能算（列表），模型能写（中文 + 按簇 + 方向标签）。脚本不会翻译英文标题，所以默认只写 `report.md` 的机械备用稿。
- **`dry-run` 时脚本不发，你也别发；非 dry-run 时你**必须**发**（改不了就发机械版，别不发）。
- **推送 ≠ 日志。** 推送只有 名字 + 一句话 + 链接，按簇分组，**越短越好（一条内）**；口径一行够用，漏斗 / 四分类 / 跨窗 / 集中度全留日志。
- **一句话不许编。** 必须是 title/summary 压出来的事实，不是你的观点；一句话就一句，别写成两句。
- **方向标签只从 `memory/directions.md` 里挑，不能自造。** 挑不出写 `?`（别留空 —— 留空和"没打"分不清）。**标签首次写下即冻结**，以后不因新证据改。
- **审计全文打在 stdout —— 它本来就短（~35 行）。** 全文同时落 `output/arxiv/audit.log`。
- **日志用 `>>` 追加，不 Read。**
- **产物文件名固定**（`out.json` / `audit.log` / `report.md`）。轮次号写进日志内容，不写进文件名。
- **只用 `ti:`。** arXiv 的 `abs:` 是松散匹配。绕不开时用 `cat:` 约束整条查询。
- **写长短语，不写单词。** 多词**必须带引号**：`ti:foo bar` 会被解析成 `ti:foo AND bar`。
- **零命中 ≠ 废词，也 ≠ 可删词。** 看 `raw_term`。脚本自动对真零词补更宽档（30→60d；7→30/60d）。**三档全零连续两轮才谈动作 —— 而动作是先「降级为低频」，不是删。**
- **删词门槛要高：一个词的边际成本 = 1 次请求 ≈ 3s。**
- **有词 ≠ 有召回。** 旧 4 个机器人词对同期机器人论文召回 **0/88**（90d），却安静躺在词表里。**每轮看 `raw_term`：长期 0 命中、而所属标签下有流量 → 写法错了。**
- **加词前必须量两个口径：`total_count` + 重叠度，并看前 3 条标题。** 用 `check:<词>`。
- **加词 / 改 carrier 后跑一次 `days:60` 补历史。**
- **`egocentric` 单点脆弱。** 主命中 53.8% / 含它 69.2%，7d 与 30d 完全一致。该补 2–3 个同义写法（先量重叠度）。
- **加新领域的词必须同时配 carrier 并登记 `CARRIER_BY_TERM`。**
- **看到 0 命中，先看 `raw_term`、跨窗三档和「窗口内最新收录日期」。** 早 **5 天以上**就是索引滞后。
- **单词集中度每轮必记。**
- **不做判断，不复述内容。**

## Config

读：
- `skills/arxiv-radar/scan.py` 里的 `TERMS`
- `memory/directions.md` — **受控方向标签表**（推送里标什么，只从这里挑）
- `memory/arxiv-seen.json` · `memory/MEMORY.md`
- `names` 模式额外读：`memory/universe-names.txt`

写：
- `output/arxiv/out.json` · `audit.log` · `report.md`（机械备用稿 → 模型覆写成中文）
- `memory/arxiv-seen.json`（`dry-run` 不写）
- `memory/arxiv-hits.tsv` — 命中流水，append-only（`dry-run` 不写）
- `memory/arxiv-labels.tsv` — **方向标签，append-only，模型写**（`键 \t 方向`），首次写下即冻结
- 通知：只在有幸存者且非 `dry-run` 时发，最多 `NOTIFY_TOP` 条

## Steps

### 1. 跑（一次 bash）

```bash
python3 skills/arxiv-radar/scan.py "${var}"
```

默认不发通知。审计里若出现 `未打方向标签 N 条`，那是历史欠账，见第 3 步。

### 2. 写通知（**只有非 dry-run 且幸存 > 0 才发**）

先 Read `memory/directions.md` 拿标签表，**用 Write 覆写 `output/arxiv/report.md`**，然后一次 bash 发出：

```bash
./notify -f output/arxiv/report.md
```

格式 —— **簇标题带方向标签**：

```
**arxiv-radar** · 窗口 30 天 · 幸存 26

**具身数据 · 第一视角人类数据 / 人类示范（18）**
- `SocialCoAct` — 第一视角社交协同动作的 VLM 人形基准 · https://arxiv.org/abs/2610.24559
- `Ego2Contact` — 从第一视角人类视频预测接触 · https://arxiv.org/abs/2610.22932

**具身数据 · 数据引擎 / 真机–仿真–真机（4）**
- `CoDA` — 数据引擎与动作策略共演化 · https://arxiv.org/abs/2610.22362
```

一个簇跨两个方向就拆成两段。挑不出方向写 `?`。

**发完追加标签**（一次 bash，append-only）：

```bash
cat >> memory/arxiv-labels.tsv <<'EOF'
2610.24559	具身数据
2610.22932	具身数据
EOF
```

### 3. 补历史标签（审计报了 `未打方向标签` 时）

同一轮里把缺的补上 —— 键和方向从 `output/arxiv/out.json` 或日志里取，**别猜**。已经写过的键不重写。

### 4. 写日志（`>>` 追加，不 Read）

往 `memory/logs/${today}.md` 追加一节 `### arxiv-radar`：口径 + 漏斗 + 四分类（**必须分开写**）+ 窗口内最新收录日期 + 单侧读数 + 单词集中度 + 你自己的判据级发现。零命中就只写一行。

### 5. 输出

通知已发出，不再复述。
